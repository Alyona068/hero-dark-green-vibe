# Hero-секция лендинга-портфолио вайбкодера

## Задача
Создать только Hero-секцию на `/` (сейчас там плейсхолдер шаблона). Остальные части проекта не трогать.

## Стиль (по референсу)
- Тёмный фон (почти чёрный с холодным зелёным отливом), эффект «серверной/tech-среды»: мягкие световые пятна, тонкая сетка/линии, вертикальные световые «коридоры».
- Неоново-зелёный акцент (~#00e676 / #4ade80), свечение (glow) вокруг ключевых элементов.
- Крупный жирный плакатный заголовок капсом, узкоеletter-spacing, как в референсе («СТРАТЕГИЯ УСПЕХА»).
- Плавающие круглые бейджи с неоновыми иконками (лапма, сеть, глобус, график, щит) — вместо человека (мужчину убрать).
- Строгая типографика без скруглённых «дружелюбных» форм.

## Контент
- Заголовок: «Создаю AI-продукты через вайбкодинг» (крупно, капсом).
- Подзаголовок: короткая строка про AI-продукты/вайбкодинг в стиле референса (мелкий текст с зелёным акцентом).
- Кнопки: «Посмотреть проекты» (основная, зелёная) и «Связаться» (вторичная, тёмная с рамкой).
- Плавающие неоновые иконки-бейджи по бокам заголовка.

## Реализация
1. `src/routes/index.tsx` — новый Hero: композиция по референсу (центрированный заголовок, иконки слева/справа), полностью адаптивный (мобильный: иконки уменьшаются/скрываются, кнопки в столбец). Свой `head()` с уникальным title/description/og.
2. `src/styles.css` — добавить токены темы: тёмный фон с зелёным отливом, неоново-зелёный primary, цвета свечения (oklch, семантические токены, без хардкода цветов в компонентах).
3. `src/routes/__root.tsx` — подключить шрифт плакатного типа (например, Archivo Black / Montserrat ExtraBold) через `<link>`, обновить root-метаданные.

## Проверка
- Сборка без ошибок (build-errors.log).
- Playwright-скриншот десктоп и мобильного вьюпорта: композиция, свечение, кнопки, адаптивность.
